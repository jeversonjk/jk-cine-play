# JK CINE PLAY 🎬
Aplicativo Android / Android TV / TV Box com Painel Administrativo
✅ Ativação por MAC
✅ Suporte a Xtream Codes e M3U8
✅ Funciona com servidores HTTP
✅ Otimizado para TV e Box

## 📁 Estrutura
- `/app` → Aplicativo Expo React Native
- `/api` → Servidor e API REST
- `/painel-admin` → Interface de administração
- `/banco_dados` → Script SQL

## 🚀 Como usar
1. Crie o banco de dados MySQL usando `schema.sql`
2. Configure a API em `/api/config/db.js`
3. No app, configure o IP da API em `app/src/services/api.js`
4. Instale dependências: `npm install` em cada pasta
5. Execute a API e o App
